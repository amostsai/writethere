# WriteThere — 手機手寫板

把手機當成電腦的文字輸入板。使用手機內建的手寫輸入法寫好文字，按「傳送」，文字就會透過貼上指令送到電腦目前取得焦點的輸入框。手機使用瀏覽器即可，免安裝 App。

## 下載

目前版本為 **0.2.6**，請依電腦系統下載：

| 電腦系統 | 下載連結 | 啟動方式 |
| --- | --- | --- |
| Windows x64 | [下載 writethere.exe](https://github.com/amostsai/writethere/releases/download/0.2.6/writethere.exe) | 雙擊執行 |
| Linux x64 | [下載 writethere](https://github.com/amostsai/writethere/releases/download/0.2.6/writethere) | 加上執行權限後啟動，見下方步驟 |
| macOS | 尚未提供可下載的執行檔 | 待原生建置與驗證 |

也可以到 [所有版本與下載頁面](https://github.com/amostsai/writethere/releases) 查看更新。在版本頁面的 **Assets** 選擇上表的執行檔；`Source code` 是原始碼，需要自行編譯。

執行預先編譯的程式不需要安裝 Rust 或 Python。Linux 版本在 Ubuntu 26.04 編譯，目前以 GNOME／Wayland 桌面為驗證環境，其他發行版可能需要相容的系統函式庫。

## 開啟程式

### Windows

下載 `writethere.exe`，雙擊即可開啟 WriteThere 視窗。

### Linux

在下載檔案所在的資料夾開啟終端機，執行：

```sh
chmod +x writethere
./writethere
```

啟動後，在系統授權視窗允許鍵盤與剪貼簿控制。若先前拒絕授權，可按 WriteThere 的「重新授權」。桌面需提供 OpenGL／EGL、XKB 與 XDG Desktop Portal。

## 手機配對與使用

1. **手機與電腦連上同一區域網路**，例如同一個 Wi-Fi，也可以手機分享熱點給電腦。
2. 在電腦開啟 WriteThere。
3. 用手機掃描視窗中的 **QR code**，以瀏覽器開啟輸入網頁。也可將視窗中顯示的完整連線網址複製到手機瀏覽器。
4. 在手機輸入電腦顯示的 **6 位數配對驗證碼**，完成配對。
5. 在電腦點選希望文字出現的地方。
6. 在手機的文字框中，透過手機內建輸入法（注音、手寫、語音...）輸入文字，再按 **「傳送」**。

| 手機模式 | 電腦送出的快捷鍵（Windows／Linux） |
| --- | --- |
| 一般（預設） | Ctrl＋V |
| 終端機 | Ctrl＋Shift＋V |

看到 **「已送出貼上指令」** 代表快捷鍵已送出，請在電腦確認貼上結果。切換到其他電腦輸入框後，下次傳送會貼到新的焦點位置，工具視窗不會搶焦點。

- 文字與換行會保留，程式不會額外按 Enter；文字本身的換行在終端機仍可能執行指令。
- 傳送會取代電腦原本的剪貼簿內容。
- 傳送期間無法重複點擊。成功或失敗後，手機文字都會保留，需要時自行按「清空」；斷線後不會自動重送。
- 程式不保存輸入歷史，連線僅供區域網路使用。

## 設定與結束

- **連接埠：** 預設為 `39945`。在電腦視窗修改後按「儲存」，下次啟動就會使用新值；目前的連線不會立刻切換。
- **更換手機：** 一次只允許一個手機配對。按「中斷手機連線／更新驗證碼」，再用新手機配對；手機斷線約 30 秒後也會釋放配對。
- **結束程式：** 關閉電腦上的 WriteThere 視窗，服務就會停止，手機無法繼續傳送。
- **重複開啟：** 同一電腦使用者一次只能執行一個 WriteThere，第二次啟動會直接結束。請使用已開啟的視窗。

## 常見問題

**手機打不開網頁？** 確認使用本次啟動顯示的 QR code 或完整網址、手機與電腦的區網可互通，並檢查電腦防火牆是否允許目前設定的 TCP 連接埠。訪客 Wi-Fi 或虛擬機的網路設定可能阻擋裝置互連。

**顯示已送出，但電腦沒有文字？** 確認目標輸入框有焦點、模式選擇正確，而且授權仍有效。Windows 上，WriteThere 與目標程式的權限等級須相同。

**顯示連接埠被占用？** 關閉占用該連接埠的程式，或儲存其他連接埠後重新啟動 WriteThere。

**Windows 雙擊沒有視窗？** 先檢查 WriteThere 是否已經在執行；其他啟動問題請參考 [Windows 啟動診斷](docs/windows-startup.md)。
