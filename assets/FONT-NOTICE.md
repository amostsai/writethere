# Embedded fonts

- `NotoSansCJK-Regular.ttc`: Noto Sans CJK regular, Traditional Chinese face (index 3).
- `NotoSansTC-Bold.ttf`: Noto Sans TC Bold, version 2.004-H2, used for the pairing code.
